# Domain Terminology & Glossary — Neuro-Symbolic Logic Reasoner Studio

This glossary provides authoritative mathematical and algorithmic definitions for all concepts utilized across `tp-neuro-symbolic-reasoner`.

---

### Satisfiability Modulo Theories (SMT)
Computational logic problem determining whether mathematical formulas are satisfiable with respect to background theories such as arithmetic, arrays, and bitvectors.

### First-Order Logic (FOL)
Formal mathematical language using predicates, functions, and quantifiers (forall, exists) to state unambiguous facts about a domain.

### Soundness & Completeness
Soundness guarantees every proven theorem is true; completeness guarantees every true theorem can be proven.
